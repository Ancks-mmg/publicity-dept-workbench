## 一、这是什么

「宣传部工作台」是团委宣传部内部使用的**一体化工作台**，包含三个核心模块：

| 模块 | 作用 |
|---|---|
| **云盘（资料库）** | 按文件夹层级管理宣传部的全部资料（部员档案、活动素材、设计源文件、制度文件等），支持逐层建子文件夹、上传、预览、下载 |
| **工作总览 / 历史归档** | 部门工作事项的台账，支持彩色表头、列筛选、斑马纹、单条归档与修改留痕 |
| **设置 / 数据管理** | 账号权限、数据维护入口 |

系统形态为「**云端数据库 + 静态站点 + Android 壳**」：
- 网页端部署在云端，浏览器直接访问；
- Android 端是 WebView 壳，加载同一个线上地址，登录态与数据完全共用。

---

## 二、适用范围与使用对象

- **使用对象**：团委宣传部在岗成员（部长权限可读写全部数据）。
- **适用场景**：日常资料归集、活动素材分发、工作台账登记与归档、资料检索。
- **不适用**：对外发布、非部门成员共享（当前权限模型仅面向部门内部）。

## 五、操作要点

### 云盘
1. 逐层点进文件夹，或用「新建文件夹」在任意层加子分类。
2. 「上传文件」可传单个文件；**「同步本地文件夹」**可在电脑上一次选整个目录，系统按相对路径自动归位（首次批量导入推荐用这个）。
3. 点文件名即**应用内预览**：图片 / 视频 / 音频 / 文本 / PDF 均可直接看；Office 类无法渲染，会给出「下载」与「新窗口打开」入口。
4. 图标徽标替换：直接替换 `logo.jpg` 即可（保持同名）。

### 工作总览 / 历史归档
- 表头带彩色分组，点列头「▼」可展开该列的去重筛选。
- 每行操作：**编辑 / 归档 / 历史 / 删除**。点「归档」会把该条写入「历史归档」并从工作总览移除。
- 所有增删改均有触发器留痕，可在「历史」里追溯。

## 六、部署与二次开发

### 网页端部署
`1-站点源（可直接部署）` 是一个完整静态站点，**保持内部相对路径**上传到任意静态托管（或平台的「发布为应用」）即可运行，无需构建。

### Android 端重新打包
- 工程源码位于开发工作区的 `XcbApp/`（**必须放在纯英文路径**，中文路径会被 Android Gradle Plugin 直接拒绝）。
- 工具链：JDK 21（Android Studio 自带 jbr）+ Gradle 8.5 + AGP 8.2.2 + Android SDK 34；`minSdk 24`（Android 7.0+）。
- 包名 `com.xcb.workbench`，入口 `MainActivity`，纯 `android.app.Activity` + `WebView`，零第三方依赖。
- 壳已实现：加载进度条、断网重试、返回键回退网页历史、**文件选择器（`onShowFileChooser`，让上传功能在 App 内可用）**、系统下载管理器接管下载、站内链接留壳 / 站外走系统浏览器。
- **签名密钥库**：`XcbApp/keystore/xcb-release.jks`（别名 `xcb`，口令见密钥管理记录）。**升级版本必须使用同一密钥签名**，否则无法覆盖安装。

## 七、已知限制与注意事项

| 项 | 说明 |
|---|---|
| 单文件上传上限 | 受平台网关与共享存储限制，**约 50MB 上下**（实测 27MB PDF 成功、76MB 及以上失败）。超限文件请先压缩（PPT 可用「去嵌入字体 + 图片降采样」方式压到 20MB 内）。 |
| 全角标点文件名 | 云存储路径不接受全角标点（如 `（）`、`：`），系统已自动把物理路径转成 ASCII，界面上仍显示原始中文名，不影响使用。 |
| 云盘实体文件 | 站点源与 APK 为**程序本体**；云盘中的业务资料（878MB，含 100 个文件）需在电脑浏览器用「同步本地文件夹」补传，超大视频（约 535MB）暂无法上传。 |
| Office 文件预览 | 浏览器无法渲染 docx/pptx/xlsx，属设计限制；预览浮层会提供下载与新窗口打开入口。 |
| 权限模型 | 当前所有已注册账号均为部长权限（可读写全部数据）。如需细分只读 / 编辑权限，需另行设计 RLS 策略。 |
